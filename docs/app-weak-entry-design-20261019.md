# 錯題站加「各科 app 待加強」入口——設計書（交辦 #3016，2026-10-19）

目標：五年級 11/5（四）～11/6（五）第一次定期評量考高分。孩子打開「錯題複習」就看得到**所有該補的題**：
①學校小考錯題（現有）②四科 app 裡待加強的題（範圍內）③考古挑戰（可選、標示較難）；kind:"out"（考不到）不列。

## 0. 不變量（照律師定的原則，下面每一節都從這裡推）

| # | 不變量 | 由誰保證 |
|---|---|---|
| I1 | 一張卡只有一份記憶狀態與「學會／待加強」判定，由**該科站**維護。錯題站**不存、不寫**任何科目卡的作答紀錄 | 錯題站只讀 `g5sci.v3`／`g5math.v2`／`g5chi.v1`／`g5soc.v1`，程式裡沒有任何寫這四個 key 的路徑；e2e 驗四個 key 讀前讀後逐字相同 |
| I2 | 停出名單（out／challenge）只有一份，在各科站 | 錯題站**不抄**名單、也不抄 `weakCard`；題數一律由各科站自己提供的函式算（第 2 節） |
| I3 | 量不到就說量不到，**不顯示 0** | 0 只在「讀到紀錄、該科函式算出 0」時出現；其他七種狀態各有一句話（第 1.4 節） |
| I4 | 錯題站現有存檔設計（單一寫入分頁、Web Locks、讀檔只接受歷代格式）一字不動 | 新功能是獨立唯讀區塊，不經 `createController`，不碰 `g5wrong.v1` |
| I5 | 不再改回逐題合併／時間戳 merge | 本功能不合併任何資料；兩份來源（本機、雲端）只「選一份來看」，不混 |

## 1. 資料怎麼取得

### 1.1 兩個來源

| 來源 | 讀法 | 什麼時候有 | 新鮮度 |
|---|---|---|---|
| **本機** | `localStorage.getItem(各科 key)`（六站同網域 windsorya.github.io，同一個瀏覽器容器裡讀得到彼此的 key） | 孩子在**同一個容器**（同一個 Safari、同一台電腦的同一個瀏覽器）練過該科 | 即時 |
| **雲端** | 家庭同步 GAS：`POST {op:"get", code:<g5sync.code>, key}` → `{ok:true, rev, data, updated}`（`g5-help/gas/core.js` `handle()`；rev 0＝雲端沒有這科） | 這個容器有家庭碼，且孩子練該科的那個容器有開同步（科目站作答後數秒內 PUT，devlog 2026-10-15） | 最後一次上傳；`updated` 是**上傳時間不是練習時間** |

### 1.2 iOS 主畫面圖示的隔離（為什麼兩個來源都要）

- [已驗證：WebKit bug 181849，2022 年 WebKit 開發者留言 by design] 主畫面圖示開的網頁與 Safari 的 localStorage 分開；devlog 2026-10-15 律師確認孩子是從主畫面圖示開。
- [未驗證] 兩個**不同主畫面圖示**（錯題站、自然站）彼此是否共用 storage：查到的 WebKit 文件與 bug 都沒寫；WWDC23 只說 web app 與瀏覽器分開。設計**不依賴**這件事：最壞情況（各圖示各自一個容器）時本機讀不到，就走雲端。
- 所以：本機讀得到就用；同時用家庭碼讀雲端；兩份都有就選「練過比較多」的那份（1.3）。

### 1.3 兩份都有時選哪一份

照律師 2026-10-15 的判準（「應該要以最新的複習進度為準，通常會是練習題目比較最多的那一次記錄」，sync.js `autoResolve` 同一判準）：
比 `answers`（作答紀錄筆數），平手比 `seen`（練過題數），再平手用本機（她眼前這份）。
`answers`、`seen` 由**各科站的函式**回傳（第 2 節），錯題站不自己解析科目存檔。兩份字串完全相同時只算本機一份。
**只選一份，不合併**（I5）。

### 1.4 每一科的顯示狀態（I3）

| 狀態 | 條件 | 畫面（孩子看得懂的話） |
|---|---|---|
| 讀取中 | 該科函式還沒載完，或本機沒有、雲端還在讀 | 「讀取中…」 |
| 有數字 | 至少一份紀錄被該科函式讀懂 | 「待加強 N 題」＋今天可練幾題；N＝0 時「沒有待加強的題」 |
| 量不到：沒提供 | 該科站還沒有 `weak-export.js`（404）或連不上 | 「量不到：自然站還沒提供待加強題數（或現在連不上網路）」 |
| 量不到：格式不對 | 檔案載到了但介面不符（第 2 節驗證不過），或改到錯題站自己的全域變數 | 「量不到：自然站提供的題數資料格式不對」 |
| 量不到：讀不懂 | 有紀錄，但每一份都被該科函式判讀不懂 | 「量不到：自然站的紀錄讀不懂」 |
| 量不到：沒同步 | 本機沒有、這台沒有家庭碼 | 「量不到：這台裝置沒有自然站的紀錄，也還沒開跨裝置同步」 |
| 量不到：雲端讀不到 | 本機沒有、雲端請求失敗或回應不合格 | 「量不到：這台裝置沒有自然站的紀錄，雲端暫時讀不到（可能沒有網路）」 |
| 量不到：雲端也沒有 | 本機沒有、雲端 rev 0 | 「量不到：這台和雲端都還沒有自然站的紀錄」；若 `g5sync.auto` 存在（這台是自動開的同步、還沒跟家人連上）加一句請到「跨裝置同步」貼家裡的連結 |

總數「各科 app 待加強共 N 題」只加**有數字**的科目；有任何一科量不到就寫「（國語量不到，沒算進去）」。

### 1.5 什麼時候重讀

開頁一次；回到這頁（`visibilitychange` → visible，例如從科目站返回）；同容器別的分頁改了科目 key（`storage` 事件，只重讀本機）；按「重新讀取」；
家庭碼換了（別的分頁改：`storage` 事件；同一頁的 sync.js 自動開同步或貼家裡連結：沒有 storage 事件，每 5 秒讀一次 `g5sync.code` 比對，不連網）。
雲端每科最多 30 秒讀一次（cap-why：每次 get 會在 GAS 端取一次寫入鎖 `store.withLock`，和科目站的上傳搶同一把鎖；30 秒對「從科目站練完回來」的情境已夠即時）。

## 2. out／challenge 怎麼排除：各科站提供的最小介面（需要 william-4c）

錯題站**不抄停出名單、不抄 weakCard、不抄 BANK 組裝**（I2）。改由每個科目站在自己網站根目錄多放一個檔：

`https://windsorya.github.io/<站>/weak-export.js`（例：`g5-sci-review/weak-export.js`）

```js
// 由該站 build 從同一份 core.js／題庫／停出名單產生；除了 window.G5WeakExport 以外不得新增或改動任何全域變數
window.G5WeakExport = window.G5WeakExport || {};
window.G5WeakExport["g5sci.v3"] = {
  api: 1,
  key: "g5sci.v3",
  links: { weak: null, challenge: null },   // 有「直接開練」的網址就填（第 3 節），只能是本站網址；沒有填 null
  summarize: function (raw, nowMs) {
    // raw＝localStorage 或雲端那份原始字串（不會是 null）；nowMs＝Date.now()
    // 讀不懂 ⇒ {ok:false}
    // 讀得懂 ⇒ {ok:true, answers, seen, weak, weakToday, challenge, challengeToday, out}（全部非負整數）
  }
};
```

| 欄位 | 定義（由該科站決定，錯題站照抄顯示） |
|---|---|
| `answers` | 存檔裡作答紀錄筆數（sync.js `practiceScore` 第一項：全部 `log` 陣列長度） |
| `seen` | 練過題數（`cards[*].seen` 加總，practiceScore 第二項） |
| `weak` | 範圍內（不是 out、不是 challenge）的待加強題數＝**該站「練待加強的」實際會出的那一群**，不管今天練過沒 |
| `weakToday` | 其中今天還能練的（今天練過的明天才出）；≤ `weak` |
| `challenge`／`challengeToday` | 考古挑戰（kind:"challenge"）裡待加強的題數／今天能練的；≤ 關係同上 |
| `out` | 考不到（kind:"out"）的待加強題數——**錯題站不顯示、不加總**，只留給家長對帳與測試 |

錯題站的驗證（不合就當「格式不對」）：`api===1`、`key` 相符、`summarize` 是函式；回傳 `ok:true` 時七欄都是非負整數且 `weakToday≤weak`、`challengeToday≤challenge`；`links` 只接受該站自己網址開頭的字串。
`summarize` 丟例外＝那一份讀不懂。載入後若錯題站自己的全域（`G5WrongCore`、`G5WrongApp`、`G5Tones`、`G5Sync`、`G5WrongBank`、`G5AppWeak`）被換掉，換回原物件並把該科標「格式不對」。

為什麼不用其他做法：

| 做法 | 不採用的理由 |
|---|---|
| 錯題站自己載 `retired.js`／`*bank.js` 再算 | 違反 I2（等於第二份 weakCard 與 BANK 組裝）；自然站題庫在 `app.html` 裡載不到；數學站 RETIRED 沒匯出 |
| 科目站把摘要寫進 localStorage（`g5weak.*`） | iOS 各容器隔離時讀不到；雲端白名單沒有這種 key，要改 GAS |
| 隱藏 iframe 開科目站 | 會跑起科目站的存檔、鎖與自動同步（寫入、PUT），違反 I1 |

#3010（out 連到期複習也停）、#3006（考古挑戰）改了「練待加強的」會出哪些題時，只要 `weak-export.js` 跟著同一份程式重 build，錯題站不用改、也不用重新部署。

## 3. 深連結

- [已驗證 2026-10-19] 四個科目站目前除了 `#sync=` 以外不讀任何網址參數；「練待加強的」是首頁「小考前想全部練一次」每個單元各一顆（`data-rvweak`），沒有全科一顆。
- **v1**：`links.weak` 是 null 時，按鈕「去自然站」連到該站首頁，旁邊一行說明「到首頁『小考前想全部練一次』，各單元按『練待加強的』」。
- **請 william-4c 加（可選，做了就把網址填進 `links`）**：`#go=weak`＝開頁後直接開一輪「全部單元、範圍內的待加強」（沒有就捲到小考複習區）；`#go=challenge`＝直接開考古挑戰。用完 `history.replaceState` 拿掉，重新整理不重開。錯題站拿到 `links.weak` 就把按鈕改成「直接練自然待加強的」。
- 連結與現有切換列一樣是同分頁開啟（不加 target）。[未驗證] 從主畫面圖示開時跨路徑連結會不會留在同一個容器——與切換列現況相同，本功能不改變它。

## 4. 畫面

位置：首頁 `#main`（①學校小考錯題）下面，新區塊 `#appWeak`；練習中（本頁正在出題）隱藏，回首頁再出現。
②「各科 app 裡待加強的題」：四科一列一科（自然、數學、國語、社會，同切換列順序）：科目、狀態句、按鈕；底下小字「依這台裝置的紀錄」或「依雲端紀錄（10/19 21:30 上傳）」。
③「考古挑戰（可選，比較難）」：只列有數字且 `challenge>0` 的科目；按鈕連 `links.challenge`，沒有就連首頁。
out 不出現在任何地方。

## 5. 不做的事

不寫四個科目 key、不另存科目卡紀錄、不改 `g5wrong.v1` 格式與單一寫入設計、不改四個科目站的 `src/app.html`／`src/core.js`／e2e、不在錯題站列停出名單、不把「量不到」顯示成 0。

## 6. 測試計畫

單元（`tests/appweak.test.js`，node）：
- 介面驗證：`api`／`key`／`summarize` 缺一不可；回傳欄位負數、小數、字串、`weakToday>weak` 一律不合格；`links` 別站網址丟掉。
- 選份：本機 vs 雲端比 answers→seen→本機；兩份相同只算一份；一份讀不懂用另一份；`summarize` 丟例外＝讀不懂。
- 八種狀態各一例；**沒有任何一種量不到的狀態產生數字 0**；總數不含 out、不含量不到的科目、不含 challenge。
- 雲端回應驗證：rev 0 必須 data null；rev>0 必須字串；`ok:false`／缺欄位＝讀不到。

e2e（`tests/e2e_appweak.py`，Chromium 桌機＋WebKit iPad；`weak-export.js` 用 route 換成**合成**替身，存檔全為合成資料，不放真實姓名學校）：
- E1 同網域有各科存檔 ⇒ 顯示替身算出的正確題數（含今天可練、總數）；四個科目 key 讀前讀後逐字相同（I1）。
- E2 out 題不列：替身回 out:3 ⇒ 畫面任何地方沒有這 3 題、總數不含。
- E3 讀不到 ⇒ 「量不到」：①檔案 404 ②本機沒有＋沒家庭碼 ③雲端 rev 0 ④雲端失敗 ⑤紀錄讀不懂 ⑥替身改壞錯題站全域 ⑦替身註冊錯 key；每種都不出現「0 題」；同一頁才開同步 ⇒ 家庭碼出現後不用重新整理就改讀雲端。
- E7 同瀏覽器別的分頁改了科目 key ⇒ 這頁題數跟著更新；E8 沒有 JS 錯誤；E9 390／320px 不橫向捲動。
- E4 雲端：本機沒有、雲端有 ⇒ 用雲端並標上傳時間；兩份都有 ⇒ 用練過多的那份。
- E5 深連結：沒有 `links.weak` ⇒ 連首頁＋說明；有 ⇒ 連該網址；別站網址不採用。
- E6 練習中隱藏、回首頁出現；既有 `tests/e2e.py`、`tests/e2e_sync.py` 全綠（兩支既有測試的科目 export 一律 route 成 404，GAS 假後端只記 `g5wrong.v1` 的 get／put，避免本功能的 get 讓「sync.js 有 GET」前提假成立）。
